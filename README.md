# Packet Sniffer with Scapy 🕵️‍♂️📡

This project demonstrates a basic packet sniffing and sending application using the `scapy` library in Python. It captures and analyzes packets, displaying details about IP, ARP, TCP, UDP, and ICMP protocols. The project also sends a sample packet to an IP address.

## 🚀 Requirements

To run this project, make sure you have the following dependencies installed:

- Python 3.x 🐍
- `scapy` library 📦
- **Npcap** (Windows packet capture library) 📶

You can install the required dependencies by running:

```bash
pip install -r requirements.txt
```
